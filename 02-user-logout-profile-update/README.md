# Module 1 – Feature 2: User Logout and Profile Update

This folder contains the implementation files for the User Logout and Profile Update feature.

## Frontend
- Settings.jsx – Displays and updates user profile information.
- Shell.jsx – Handles user logout.
- AuthContext.jsx – Manages authentication and profile updates.
- api.js – Provides API communication.

## Backend
- views.py – Handles profile retrieval, profile updates, and logout requests.
- serializers.py – Validates and serializes user profile data.
- urls.py – Defines authentication API endpoints.
- models.py – Defines the user model.
